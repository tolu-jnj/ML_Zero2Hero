# Project 05: Segmentation Metrics

This metrics-focused example creates synthetic binary masks and computes pixel accuracy, mean intersection-over-union, and per-class Dice. The course distinguishes segmentation from image classification and discusses task-dependent metrics. [COURSE: 05 Expert Guide C2 W5 Live Event.pdf#slides 4-5] [COURSE: 05_Week_5_Transcript.txt#lines 150-180]

Run from the repository root with `make run-05`. Run tests with `make test-05`.

This project does not train a vision model or represent a validated inspection system. Model training, annotation policy, and regulated validation are `[GAP]` topics; metric definitions are supported by `[EXTERNAL: authoritative computer-vision evaluation references]`.
